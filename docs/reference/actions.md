# Action hooks

Generated by `mahout-devtools`. Do not edit by hand; run `composer hooks:generate`.

Every hook name is a `public const` on a `Hooks` class; its `@action` or `@filter` docblock tag decides which of the two documents the entry lands in.
The other kind lives in `filters.md`.

| Constant | Hook | Arguments | Since | Description |
|---|---|---|---|---|
| `BEFORE_MIGRATE` | `mahout/db/before_migrate` | `string $migration`, `int $batch` | 1.0 | Fires immediately before one migration's up() or down() runs. |
| `AFTER_MIGRATE` | `mahout/db/after_migrate` | `string $migration`, `int $batch` | 1.0 | Fires immediately after one migration ran and its ledger row was written. A reversal fires this too: a dropped index has to invalidate anything that cached its presence. |
| `MIGRATION_FAILED` | `mahout/db/migration_failed` | `string $migration`, `\Throwable $failure` | 1.0 | Fires when a migration throws. The failure is recorded at critical first. |
| `ORPHANS_COLLECTED` | `mahout/db/orphans_collected` | `int $rows` | 1.0 | Fires after a collection path removed orphan rows, with the count. |
| `DELETED_POST` | `deleted_post` | `int $postId` | 1.0 | Core's post deletion action: the immediate, keyed orphan path. |
| `GC` | `mahout/db/gc` | — | 1.0 | The orphan sweep's own action. The theme schedules it; this package only attaches the handler, and the handler never runs on a request path. |
| `AFTER_SWITCH_THEME` | `after_switch_theme` | — | 1.0 | Core's theme-switch action: the first-install run path. A theme has no activation hook -- register_activation_hook() is plugin-only -- and this action is the theme's equivalent. |
| `ADMIN_INIT` | `admin_init` | `string $hookSuffix` | 1.0 | Core's admin bootstrap action: the lazy run path. |
